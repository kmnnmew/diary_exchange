# 공유일기 플랫폼 — Figma AI 디자인 스펙

## 디자인 방향성 (전체 공통)

**레퍼런스 무드**: Moleskine 노트북의 질감 + Monocle 매거진의 타이포그래피 + Are.na의 미니멀리즘 + Ohayo 앱의 따뜻한 파스텔

**컬러 팔레트**:
- Background: `#F5F0E8` (오래된 종이색)
- Primary Text: `#2C2416` (짙은 먹색)
- Accent: `#C4855A` (테라코타 브라운)
- Secondary: `#8FA68E` (세이지 그린)
- Surface: `#FFFDF7` (흰 종이)
- Muted: `#B8AFA0` (연한 회갈색)

**타이포그래피**:
- 헤딩: `Playfair Display` (세리프, 이탤릭 혼용)
- 본문: `Noto Serif KR` (한글 세리프)
- UI 라벨: `DM Mono` (고정폭, 소문자)

**전체 톤**: 디지털인데 손으로 만든 느낌. 애니메이션은 천천히 스며드는 페이드. 그림자는 없고 대신 얇은 선과 여백으로 구분.

## PAGE 01 — 온보딩 / 랜딩

**레이아웃**:
- 전체 높이 100vh, 중앙 정렬이 아닌 좌측 오프셋 구성
- 배경에 얇은 가로 줄 패턴 (노트 룰드 라인, opacity 10%)
- 우측 상단에 날짜 레이블: `Mon. Mar 02` — DM Mono, 9pt, Muted 색상

**상단 영역**:
- 로고: "일기" 한 단어를 Playfair Display Italic으로 크게 (80pt), 아래에 "교환 플랫폼" 을 DM Mono 소문자 12pt로 배치
- 로고 좌측에 세로 얇은 선 1px, Accent 컬러

**히어로 섹션**:
- 메인 카피: `"오늘의 하루를 누군가에게"` — Playfair Display, 48pt, 2줄 줄바꿈
- 서브 카피: `"하루에 한 번, 당신의 일기가 누군가에게 전달됩니다."` — Noto Serif KR, 16pt, Muted 컬러
- CTA 버튼: 테두리만 있는 버튼 (border 1.5px, Accent 컬러), 텍스트 `시작하기` — 호버 시 배경이 Accent로 채워짐
- 버튼 아래 `또는 로그인` — DM Mono 10pt, 링크 스타일

**우측 데코레이션**:
- 살짝 기울어진 일기장 카드 목업 (rotation: -3deg)
- 카드 위에 날짜 도장 이미지, 스탬프 이미지
- 카드 배경색: Surface (`#FFFDF7`), 테두리 1px Muted

**하단 피처 힌트**:
- 3개 아이콘 + 라벨 가로 나열
  - `익명 교환` / `그룹 일기` / `AI 답장`
  - 아이콘: 선 드로잉 스타일 (stroke only, no fill)
  - 라벨: DM Mono 10pt

## PAGE 02 — 회원가입 / 로그인

**레이아웃**:
- 좌우 2분할: 좌측 40% 텍스처 배경 + 우측 60% 폼 영역
- 좌측: 룰드 노트 텍스처 + 손글씨 느낌의 인용구 `"오늘도 잘 왔어요."` (Playfair Display Italic, 36pt)
- 우측: 흰 종이 배경, 상단 여백 넉넉히

**폼 구성**:
- 입력 필드: 밑줄만 있는 언더라인 스타일 (border-bottom만 존재), 라벨이 위에 float
- 필드 항목: 이메일, 비밀번호
- 구분선: `— 또는 소셜 로그인 —` (DM Mono, Muted)
- 소셜 버튼: 구글 / 애플, 텍스트만 있는 outline 버튼

**약관 동의**:
- 체크박스 대신 토글 슬라이더 (pill shape, Secondary 컬러)
- 텍스트: `서비스 이용약관`, `개인정보 처리방침`

**하단**:
- `계정이 있으신가요? 로그인` — 링크

## PAGE 03 — 홈 (메인 대시보드)

**레이아웃**:
- 좌측 사이드바 (60px 고정폭) + 메인 콘텐츠 영역
- 사이드바: 배경 Primary Text 색상, 아이콘만 흰색으로 (선 드로잉)
- 상단 바 없음 — 날짜가 메인 영역 상단에 크게 표시됨

**메인 영역 상단**:
- 날짜 헤딩: `2026년 3월 2일, 월요일` — Playfair Display, 28pt
- 서브텍스트: `오늘의 일기를 아직 작성하지 않았어요.` 또는 `오늘의 일기가 전달 중이에요.` — 상태에 따라 변경

**중앙 카드 영역**:
- 오늘의 일기 작성 카드: 룰드 라인 배경, 테두리 1px, 모서리 약간 둥글게 (border-radius 4px)
- 카드 상단에 날짜 도장 자리 (점선 원형)
- 카드 안에 `오늘 하루를 기록해보세요...` placeholder (Noto Serif KR Italic, Muted)
- 하단에 `꾸미기`, `전송하기` 버튼

**상태 뱃지** (카드 우상단):
- `전달 중`, `코멘트 도착`, `완료` — DM Mono 9pt, 작은 pill 형태

**하단 섹션**:
- 최근 교환 기록 3개: 작은 카드들이 가로 스크롤, 날짜 + 교환 유형 + 감정 태그 표시

## PAGE 04 — 일기 작성

**레이아웃**:
- 전체 화면 에디터, 사이드바 숨김
- 배경: 선택된 종이 디자인 (기본: 룰드 노트)
- 상단 얇은 바: 뒤로가기 화살표 + 날짜 + 글자 수 카운터 (DM Mono)

**에디터 영역**:
- 폰트: Noto Serif KR 16pt, 줄간격 2.0
- 커서: 세로 바 대신 밑줄 커서 (손글씨 느낌)
- 좌측 마진에 세로 빨간 선 1px (노트 마진 라인, Accent 컬러 opacity 40%)
- 상단에 날짜가 손글씨 느낌으로 자동 입력됨 (편집 불가, Muted 컬러)

**하단 툴바**:
- 고정 하단 바, 배경 Surface
- 아이콘 버튼들: `종이 변경`, `스탬프`, `감정 태그`, `날씨`
- 우측에 `전송하기` 버튼 (Accent 배경, 흰 텍스트)

**전송 전 확인 모달**:
- 하단에서 슬라이드업
- `누구에게 전달할까요?` 섹션
- 3가지 선택: `익명 교환`, `그룹 교환`, `AI와 교환` — 라디오 선택이 아닌 카드 탭 방식
- `전송하기` 최종 버튼

---

## PAGE 05 — 수신된 일기 / 코멘트 작성

**레이아웃**:
- 상단 70%: 수신된 일기 뷰어 (읽기 전용)
- 하단 30%: 코멘트 작성 영역

**일기 뷰어**:
- 수신한 일기가 실제 종이처럼 렌더링
- 상단에 `익명의 누군가로부터` (DM Mono, Muted) + 날짜
- 종이 디자인/스탬프가 원본 그대로 유지됨
- 스크롤 가능, 페이드 마스크로 하단 처리

**코멘트 작성 영역**:
- 구분선: 얇은 가로선 1px
- `답장을 남겨보세요` 레이블 (DM Mono 10pt)
- 텍스트 입력 박스 (룰드 배경, 최소 30자 안내)
- 글자 수: `0 / 최소 30자` (실시간 카운트)
- `전송하기` 버튼 — 30자 미달 시 비활성화 상태 (Muted 컬러)

**경고 메시지**:
- 부적절 콘텐츠 감지 시: 상단에서 내려오는 얇은 바 (배경 `#E8C4A0`, 텍스트 `#8B4513`)
- 반복 문자 감지 시 동일 방식

---

## PAGE 06 — 그룹 교환

**레이아웃**:
- 상단: 그룹 이름 + 인원 수 + 방장 표시
- 탭: `일기 교환` / `멤버` / `설정`

**일기 교환 탭**:
- 오늘 나의 일기 작성 상태 카드 (상단)
- 아래: 그룹 멤버별 교환 현황 리스트
  - 각 항목: 익명 닉네임 + 상태 뱃지 (`작성 완료`, `대기 중`, `코멘트 완료`)
  - 리스트 아이템 높이: 56px, 구분은 1px 점선

**멤버 탭**:
- 멤버 리스트, 각 항목에 `차단`, `신고` 버튼 (텍스트 링크 스타일, 우측 정렬)
- 방장 표시: 이름 옆에 작은 `방장` 라벨 (DM Mono, Accent 컬러)

**그룹 생성 모달**:
- `그룹 이름`, `최대 인원`, `공개/비공개` 토글
- 비공개 선택 시: 링크 생성 or 비밀번호 설정 옵션 나타남

## PAGE 07 — AI 교환 모드

**레이아웃**:
- 채팅 UI가 아닌 일기 교환 형식 유지
- 상단: `AI와의 교환` 헤딩 + `매일 오전 8시에 답장이 도착해요` 서브텍스트 (DM Mono)

**AI 성격 설정 (유료)**:
- 카드 형태로 AI 프리셋 목록 (기본: `따뜻한 친구`, `냉철한 관찰자`, `시인` 등)
- 선택된 카드: Accent 컬러 테두리 1.5px
- 유료 기능 안내: `나만의 AI 만들기` 버튼, 잠금 아이콘 포함

**커스텀 프롬프트 입력 (유료 전용)**:
- 말투 설정 드롭다운: `존댓말 / 반말`
- 성격 설명 텍스트 영역: `이 AI는 어떤 사람인가요?`
- 저장 버튼

**AI 답장 뷰**:
- AI 코멘트 상단에 `AI가 작성한 답장입니다.` 안내 바 (Surface 배경, Muted 텍스트)
- 24시간 무응답 자동 보완의 경우: `24시간 내 응답이 없어 AI가 대신 답장을 작성했습니다.` 동일 스타일로 표시

## PAGE 08 — 기록 보관함

**레이아웃**:
- 상단: 탭 3개 — `익명 교환` / `그룹 교환` / `AI 교환`
- 탭 아래: 연월 선택기 (좌우 화살표, 중앙에 `2026년 3월` — Playfair Display)

**일기 리스트**:
- 카드형 리스트, 각 카드:
  - 상단: 날짜 (DM Mono) + 교환 완료 여부 뱃지
  - 중간: 일기 첫 줄 미리보기 텍스트 (Noto Serif KR, 2줄 클램프)
  - 하단: 감정 태그 + 사용한 종이 디자인 미리보기 썸네일 (20x20px)
- 카드 간격: 16px, 카드 좌측에 날짜 세로 구분선 (Accent 컬러)

**상세 뷰** (카드 탭):
- 전체 화면으로 일기 + 코멘트 함께 표시
- 받은 코멘트 영역: 점선 테두리 박스, 상단에 `누군가의 답장` 레이블

## PAGE 09 — 꾸미기 / 테마 설정

**레이아웃**:
- 좌측: 실시간 미리보기 (일기 카드)
- 우측: 설정 패널

**설정 패널 구성**:

종이 디자인 선택:
- 가로 스크롤 썸네일 목록
- 잠금 아이콘: 유료 항목에 표시
- 선택 시 좌측 미리보기 실시간 갱신

스탬프 선택:
- 그리드 배열 (4열), 각 스탬프 40x40px
- 카테고리 탭: `감정` / `날씨` / `날짜`

플랫폼 테마:
- `라이트` / `다크` / `파스텔` — 가로 토글 3버튼
- 선택 시 앱 전체 색상 즉시 변경

**유료 업그레이드 배너**:
- 패널 하단 고정, 얇은 Accent 컬러 테두리 박스
- `프리미엄 디자인 전체 이용하기 →` 텍스트 링크

## 공통 컴포넌트 스펙

**네비게이션 사이드바**:
- 60px 고정폭, Primary Text 배경
- 아이콘: 집, 편집, 받은함, 기록, 설정 (각 24px, stroke only)
- 활성 상태: 좌측 3px Accent 컬러 바

**뱃지 / 상태 라벨**:
- pill 형태, 배경 없음, 테두리 1px
- 폰트: DM Mono 8pt, letter-spacing 0.05em

**모달**:
- 배경 dim: 검정 opacity 40%
- 모달 배경: Surface 색상, 테두리 1px Muted
- 진입: 하단 슬라이드업 (모바일) / 중앙 페이드인 (데스크탑)

**빈 상태 (Empty State)**:
- 일러스트 없음 — 대신 `오늘의 첫 줄을 기다리고 있어요.` 텍스트만 (Playfair Display Italic, 20pt, Muted)
- 하단에 행동 유도 텍스트 링크
