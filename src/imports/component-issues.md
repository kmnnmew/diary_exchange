## 전체 공통

**CSS 변수 누락** — 가장 먼저 고쳐야 할 것. `theme.css`에 `--bg`, `--surface`, `--line`, `--text-primary`, `--text-muted` 가 정의되어 있지 않아서 현재 배경색, 테두리색, 텍스트 색이 전부 아무것도 안 보이는 상태입니다. `--background`, `--card`, `--border` 등 기존 변수에 별칭을 추가해줘야 해요.

## Landing (랜딩 페이지)

- 히어로 제목 `text-[64pt]`가 모바일에서 화면을 가득 넘쳐흐름. 반응형 크기 조절 필요
- 상단 헤더 border가 `border-transparent`라 구분선이 아예 없어서 허공에 떠있는 느낌
- 우측 데코 카드들이 `rotate-4` 같은 비표준 Tailwind 클래스를 사용 중 — 회전이 실제로 적용 안 됨

## Auth (로그인/회원가입)

- 좌측 다크 패널이 `lg:` 이하에서 완전히 사라지는데, 모바일에서 로고나 서비스 이름이 전혀 안 보임
- 회원가입 시 약관 토글이 두 줄짜리 긴 텍스트와 나란히 있어서 좁은 화면에서 레이아웃이 깨짐

## Home (홈)

- 오늘의 상태 카드 왼쪽 색상 바가 항상 `text-muted` 색으로 고정되어 있고, 상태에 따라 바뀌어야 한다는 주석만 있고 실제로 구현이 안 되어 있음
- 최근 기록 리스트에서 날짜 (`w-24`) 와 본문 사이 간격이 너무 좁아 답답한 느낌

## Write (일기 작성)

- 하단 툴바가 `left-[64px]`로 사이드바 너비에 하드코딩되어 있어서, 툴바 왼쪽 끝이 사이드바 위로 겹침 없이 딱 붙긴 하지만 반응형에서 무너짐
- 전송 바텀 시트가 `left-0 right-0`으로 사이드바까지 덮어버림. `left-[64px]`로 맞춰야 자연스러움
- 에디터 안 제목 input과 본문 textarea 사이에 시각적 구분이 없어서 어디서 제목이 끝나고 본문이 시작하는지 불분명

---

## Received (받은 일기)

- `h-screen overflow-hidden` 구조가 사이드바 포함 전체 뷰포트를 기준으로 잡혀 있어서, 실제 콘텐츠 높이 계산이 사이드바 레이아웃과 어긋남
- 코멘트 textarea가 flex 컨테이너 안에서 `h-full`인데, 부모 높이가 명시되지 않아 높이가 0으로 붕괴되는 경우 있음

---

## Archive (기록 보관함)

- 상세 뷰에서 "내가 쓴 일기"(flex-[3])와 "받은 답장"(flex-[2]) 영역이 mock 데이터가 짧으면 높이가 비율대로 늘어나지 않고 콘텐츠 높이만큼만 잡힘. `min-h` 지정 필요
- 목록의 감정 태그가 영어 raw 값 그대로 나옴 (`happy`, `calm`, `sad`). 한국어로 표시하거나 이모지로 대체 필요

---

## AIExchange (AI 일기)

- 답장 확인 탭에서 "내가 보낸 일기"와 "AI 답장" 두 영역이 `overflow-y-auto`인데 부모에 `min-h-0`이 없어서 flex 높이 붕괴 가능
- AI 성격 카드들이 가로 스크롤되는데, 스크롤바가 그대로 노출되어 감성적인 디자인과 어울리지 않음 (스크롤바 숨김 처리 필요)

---

## GroupExchange (그룹 일기)

- 그룹 카드 grid가 `lg:grid-cols-3`인데 중간 사이즈에서 카드가 너무 좁아짐
- "참여할 수 있는 방" 탭의 그룹 카드에 태그 뱃지가 있지만 스타일이 다른 뱃지들과 달라서 통일성이 없음

## Customize (꾸미기)

- 이 파일만 유일하게 `bg-card`, `border-muted`, `text-muted-foreground` 같은 Tailwind 표준 클래스를 쓰고, 나머지 파일들은 전부 `var(--surface)`, `var(--line)` 같은 CSS 변수를 씀. 완전히 다른 스타일 시스템 → 통일 필요
- 헤더 h1이 다른 페이지의 `h-[64px]` 고정 높이 레이아웃을 따르지 않아 상단 여백이 다름
- `fontFamily` 인라인 스타일이 h1, h2, h3, 버튼 전부에 따로따로 붙어 있음. `font-serif` 클래스로 통일하면 깔끔해짐
