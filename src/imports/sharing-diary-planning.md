# 🌸 공유일기 플랫폼 서비스 기획서 (최종 정리본)

---

## 1. 서비스 개요

**공유일기 플랫폼**은
하루에 한 번 작성한 일기를 누군가와 교환하는 감성 기반 일기 교환 서비스입니다.

사용자는 익명 사용자, 그룹 구성원, 또는 AI와 일기를 교환하며
자신의 하루를 전달하고, 누군가의 마음을 받는 경험을 합니다.

이 서비스는 공개 피드 기반 SNS가 아닌
**1:1 교환 중심 구조**를 기반으로 하며,
‘보여주기’가 아닌 ‘전달하기’에 초점을 둡니다.

또한 종이 디자인, 테마, 스탬프 등 꾸미기 기능을 통해
일기를 하나의 감성 콘텐츠로 완성할 수 있습니다.

---

# 2. 핵심 운영 원칙

* 하루 1회 작성 (00:00 ~ 23:59 기준)
* 전송 후 랜덤 매칭
* 코멘트 작성 후 원작성자에게 되돌아가는 왕복 구조
* 공정 매칭 알고리즘 적용
* 차단 및 신고 기능 포함
* 부적절 콘텐츠 사전 차단
* 일정 시간 내 미응답 시 AI 자동 응답 보완

---

# 3. 주요 기능

---

## I. 익명 교환 모드

### 이용 방식

* 사용자는 하루 1개의 일기 작성 가능
* 전송 시 익명의 사용자에게 랜덤 전달
* 수신자는 1회 코멘트 작성 가능
* 코멘트 작성 후 원작성자에게 일기와 함께 반환
* 원작성자는 일기와 코멘트를 함께 확인 가능
* 특정 사용자와 재매칭 원치 않을 경우 차단 가능

---

## II. 그룹 교환 모드

### 그룹 생성

* 공개 / 비공개 선택 가능
* 방장이 최대 인원 수 설정 가능
* 비공개 그룹은 링크 또는 비밀번호 초대

### 그룹 매칭 방식

* 그룹당 하루 1회 작성 가능
* 매일 다른 구성원에게 랜덤 전달
* 동일 사용자가 반복 매칭되지 않도록 설계
* 그룹 내 모든 인원이 1회 이상 코멘트 완료 전까지 중복 매칭 방지
* 1사이클 완료 후 매칭 기록 초기화

### 그룹 안전 기능

* 인원 목록에서 차단 가능
* 코멘트 수신 후 차단 가능
* 신고 기능 → 방장에게 전달
* 방장은 경고, 제한, 강제 퇴장 가능

---

## III. AI 교환 모드

### 기본 구조

* 사용자가 일기를 AI에게 전송
* 설정된 성격으로 AI가 코멘트 작성
* 매일 오전 8시에 코멘트 도착

### 무료 플랜

* 사전 설정된 AI 성격 프리셋 사용 가능

### 유료 플랜

* 사용자 맞춤 프롬프트 설정 가능
* 말투, 성격, 반응 방식 커스터마이징 가능

---

# 4. 응답 미작성 시 AI 자동 보완 기능

### 📌 목적

사용자가 일기를 보냈으나 코멘트를 받지 못하는 상황을 방지하기 위함.

---

### 📌 작동 방식

* 일기 전송 후 24시간 이내 코멘트가 작성되지 않을 경우
* 시스템이 자동으로 AI에게 해당 일기를 전달
* AI가 코멘트 작성
* 사용자에게 전송

### 📌 명확한 안내

AI가 작성한 경우,
코멘트 상단에 다음 문구 표시:

> “24시간 내 응답이 없어 AI가 대신 답장을 작성했습니다.”

👉 사용자에게 AI임을 명확히 고지

---

# 5. 부적절 콘텐츠 차단 시스템

### 📌 적용 대상

* 일기 작성 시
* 코멘트 작성 시

---

### 📌 차단 기준

* 욕설 및 비방
* 타인에 대한 공격적 표현
* 혐오 표현
* 선정적 내용
* 범죄 유도 내용
* 자해·위험 행위 조장 내용

---

### 📌 작동 방식

* 전송 버튼 클릭 시 AI 기반 콘텐츠 필터링 실행
* 부적합 판단 시 전송 차단
* 수정 안내 메시지 제공

예시 안내:

> “부적절한 표현이 감지되어 전송이 제한되었습니다. 내용을 수정해주세요.”

---

# 6. 코멘트 최소 품질 기준

감정 교환의 질을 유지하기 위해
코멘트 작성에는 최소 기준이 적용됩니다.

---

### 1) 최소 글자 수 제한

* 예: 최소 30자 이상 작성해야 전송 가능

---

### 2) 단순 반복 문자 차단

다음과 같은 코멘트는 전송 불가:

* “ㅋㅋㅋㅋㅋㅋㅋㅋ”
* “ㅇㅇㅇㅇㅇㅇㅇㅇ”
* “ㅎㅎㅎㅎㅎㅎ”
* 동일 문자 과도 반복
* 의미 없는 단어 반복

### 📌 작동 방식

* 반복 패턴 감지 알고리즘 적용
* 의미 없는 반복 문자열 비율이 일정 기준 초과 시 전송 차단
* 사용자에게 수정 요청

예시 안내:

> “의미 없는 반복 문자는 전송할 수 없습니다. 내용을 조금 더 작성해주세요.”

---

### 1) 종이 디자인 변경

* 편지지형
* 파스텔 배경
* 빈티지 스타일
* 계절 한정 테마

---

### 2) 플랫폼 테마 설정

* 라이트 모드
* 다크 모드
* 파스텔 테마
* 시즌 한정 테마

---

### 3) 스탬프 및 스티커 기능

* 감정 스탬프
* 날씨 스탬프
* 날짜 도장
* 스티커 꾸미기

---

## 무료 vs 유료 구분

### 무료 사용자

* 기본 디자인 사용 가능
* 일부 스탬프 사용 가능
* 기본 AI 프리셋 사용 가능

### 유료 사용자

* 프리미엄 디자인 전체 사용 가능
* 시즌 한정 테마 사용 가능
* 고급 스탬프 사용 가능
* AI 성격 직접 커스터마이징 가능

---

# 8. 기록 확인 기능

카테고리별 기록 확인 가능:

* 익명 교환 일기
* 그룹 교환 일기
* AI 교환 일기

확인 가능 정보:

* 작성 일자
* 감정 태그
* 받은 코멘트
* 사용한 디자인
* 교환 완료 여부

# 9. 서비스 철학

이 플랫폼은 빠르게 소비되는 SNS가 아닙니다.

* 공개 경쟁 없음
* 인기 지표 없음
* 좋아요 없음
* 팔로우 없음

핵심은 교환입니다.

하루를 보내면,
누군가의 마음이 돌아옵니다.

그리고 혹시 돌아오지 않더라도,
플랫폼은 당신의 하루를 외면하지 않습니다.
